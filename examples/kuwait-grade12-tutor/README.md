# مُعين — بوت تعليمي للصف الثاني عشر (الكويت)

بوت تعليمي شامل لجميع مواد **الصف الثاني عشر في المدارس الحكومية بدولة الكويت** (القسمان العلمي والأدبي)، مبني على [Claude Agent SDK](https://docs.claude.com/en/api/agent-sdk/overview).

> _A Claude Agent SDK example: an Arabic study bot for Kuwait public-school grade 12 — unit summaries, daily review sheets, weekly notes, weekly tests, and a voice tutor window. Not published._

## ماذا يقدّم البوت؟

| المهمة | الوصف |
|---|---|
| 📖 **تلخيص وشرح** | شرح مبسط لكل وحدة: الأهداف، الشرح بالأمثلة، جدول التعريفات والقوانين، الأخطاء الشائعة، والخلاصة |
| 🗓️ **ورقة مراجعة يومية** | ورقة قصيرة (15–20 دقيقة): الفكرة في دقيقة، ما يجب حفظه، تدريبات سريعة مع الإجابات، وتحدي اليوم |
| 📒 **مراجعة ومذكرة أسبوعية** | خريطة الوحدة، ملخص الموضوعات، جداول المقارنة، بنك التعريفات، أسئلة متوقعة، وخطة مذاكرة للأسبوع |
| 📝 **ورقة اختبار أسبوعية** | اختبار من 20 درجة على نمط وزارة التربية (اختيار، صح وخطأ، علل/قارن، مقالي/مسائل) مع نموذج الإجابة وجدول تقييم ذاتي |
| 🎙️ **النافذة التعليمية الصوتية** | تحدّث مع البوت بصوتك بالعربية؛ يجيب بشرح مختصر ويقرؤه بصوت مسموع، مع محادثة متصلة تتذكر ما سبق |

كل الأوراق قابلة **للطباعة أو الحفظ PDF** وللاستماع إليها صوتياً.

### المواد المشمولة

- **مشترك:** التربية الإسلامية، اللغة العربية، اللغة الإنجليزية
- **علمي:** الرياضيات، الفيزياء، الكيمياء، الأحياء، الجيولوجيا
- **أدبي:** الرياضيات، التاريخ، الجغرافيا، الفلسفة، علم النفس والاجتماع، الاقتصاد

## التشغيل

المتطلبات: Node.js 18 أو أحدث، ومفتاح `ANTHROPIC_API_KEY`.

```sh
cd examples/kuwait-grade12-tutor
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

ثم افتح **http://localhost:3000** في متصفح Google Chrome أو Microsoft Edge (لدعم الميكروفون والتعرف على الكلام العربي).

### طريقة الاستخدام

1. اختر **القسم** (علمي/أدبي) ثم **المادة**.
2. اختر **الفصل والأسبوع** فيقترح البوت الوحدة المقررة تلقائياً، أو اختر الوحدة بنفسك.
3. اضغط على المهمة المطلوبة. يمكنك كتابة ملاحظة مثل "ركّز على المسائل" أو "اشرح بطريقة أبسط".
4. للنافذة الصوتية: افتح تبويب **🎙️ النافذة الصوتية**، اضغط الميكروفون واسأل. فعّل "محادثة مستمرة" ليستمع البوت تلقائياً بعد كل إجابة.

### أداة سطر الأوامر (للمعلمين)

لإعداد الأوراق دفعة واحدة وحفظها في مجلد `output/`:

```sh
npm run cli -- list                              # عرض كل المواد والوحدات ومعرفاتها
npm run cli -- explain physics-1                 # تلخيص وشرح وحدة
npm run cli -- daily chemistry-2 "ركّز على pH"   # ورقة مراجعة يومية
npm run cli -- weekly-notes biology-1            # مذكرة أسبوعية
npm run cli -- weekly-test arabic-3              # اختبار أسبوعي
npm run cli -- week 1 5 علمي                     # مذكرات واختبارات الأسبوع 5 (الفصل 1) لكل مواد القسم العلمي
```

## الإعدادات

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | مفتاح Claude API (مطلوب) |
| `TUTOR_MODEL` | نموذج الـ SDK الافتراضي | لاختيار نموذج معين، مثل `claude-sonnet-5-5` |
| `PORT` | `3000` | منفذ الخادم |
| `HOST` | `127.0.0.1` | استخدم `0.0.0.0` لإتاحة البوت لأجهزة الطلاب في الشبكة المحلية |

## البنية

```
src/curriculum.ts   خريطة المنهج: المواد والوحدات والموضوعات وتوزيعها على الأسابيع
src/prompts.ts      تعليمات البوت وقوالب المهام الأربع والنافذة الصوتية
src/tutor.ts        تشغيل Claude Agent SDK مع أدوات المنهج (MCP) وبث الرد
src/server.ts       خادم الويب (بدون مكتبات إضافية) مع بث SSE
src/cli.ts          أداة سطر الأوامر
public/index.html   الواجهة: صفحة عربية RTL، الطباعة، والنافذة الصوتية (Web Speech API)
```

- البوت **لا يملك أي صلاحيات على الجهاز** (`tools: []`): لا قراءة ملفات ولا تنفيذ أوامر، فقط ثلاث أدوات للمنهج: `list_subjects` و`get_unit` و`unit_for_week`.
- التعرف على الكلام والنطق يعملان داخل المتصفح (Web Speech API)؛ يُرسَل نص السؤال فقط إلى الخادم.

## تعديل المنهج

عناوين الوحدات وموضوعاتها في `src/curriculum.ts` مبنية على الهيكل العام لكتب الصف الثاني عشر. إذا اختلف ترتيب أو مسمى وحدة في الطبعة الحالية من كتب وزارة التربية، عدّل هذا الملف فقط، وسيلتزم البوت بالتعديل في الشرح والأوراق والاختبارات. يُنصح بأن يراجع المعلم الأوراق قبل توزيعها على الطلاب.
